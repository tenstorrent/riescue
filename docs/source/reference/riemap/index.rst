RieMap - Page Table Generator
==============================

RieMap builds RISC-V page tables from declared spaces, pages, mappings (leaf PTEs),
and address constraints.

RieMap has two frontends:

- The :class:`~riescue.riemap.builder.PageTableBuilder` Python API, used directly by
  RiescueD and available to any Python consumer.
- The ``riemap`` console script, driven by a declarative JSON config.

This section is the reference material: the constraint :doc:`model`, the
:doc:`JSON configuration schema <json_reference>`, and the
:doc:`autogenerated API <api_reference>`. To get started, see the
:doc:`RieMap tutorial </tutorials/riemap/index>`; for the Python API in depth, see
the :doc:`RieMap user guide </user_guides/riemap_user_guide>`.

The source lives in ``riescue/riemap``.
